# RuGo

**Платформа аренды спецтехники, материалов и ремонта**  
Мини-приложение в мессенджере MAX для строительного рынка Воронежа

---

## О проекте

RuGo объединяет аренду спецтехники, доставку сыпучих материалов и ремонт в одну точку входа. Заказчик находит предложение по категории и району и связывается с партнёром напрямую, а партнёр размещает карточку бесплатно после модерации.

> **MVP в продакшене:** мини-приложение, каталог, заявки партнёров, личный кабинет, веб-админка и админ-бот.

## Возможности

| Раздел | Что реализовано |
|---|---|
| Каталог | Техника, материалы и мастерские с поиском по категории и району |
| Карточки | Фото, цена, характеристики и кнопка «Позвонить» партнёру |
| Заявки | Приём заявок партнёров и модерация `new → accepted / rejected` |
| Кабинет | Добавление, правка и удаление карточек партнёра |
| ЖБИ | Партнёрский каталог: разделы, категории, изделия, цены, поиск и пагинация |
| Админка | Веб-админка и админ-бот: модерация, CRUD, статистика, логи |
| Аналитика | Обезличенные события и реферальные переходы |
| Доступ | Вход и подтверждение телефона через MAX (валидация `initData`) |

## Стек

| Слой | Технологии |
|---|---|
| Backend | Java 21, Spring Boot 3.3.3, Spring Web, Validation, Spring Data JPA (Hibernate), Caffeine, Maven |
| База данных | PostgreSQL 18 |
| Интеграция | MAX Bot API, webhook / long polling, HMAC-валидация `initData` |
| Frontend | React 19, TypeScript, Vite, MAX UI, React Router (админка), Vitest |
| Инфраструктура | Nginx, systemd, Let's Encrypt |
| Тесты | JUnit 5, Spring Boot Test, H2 (тесты), Vitest, Testing Library |

## Архитектура

```
rugo/
├── rugo-common    — общие утилиты, конфигурация, исключения
├── rugo-core      — домен: сущности, репозитории, сервисы, безопасность
├── rugo-app       — публичное API и мини-приложение (порт 8080)
├── rugo-admin     — админ-бот и веб-админка (порт 8081)
├── rugo-webapp    — frontend мини-приложения (React + TypeScript)
├── rugo-admin-web — frontend админки (React + TypeScript)
└── sql/           — схема и миграции PostgreSQL
```

Публичный frontend получает данные из `/api/**`. Админка и бот работают отдельным процессом на общей базе данных.
